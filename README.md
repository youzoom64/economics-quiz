# 経済 4択問題集

経済の基礎を学べる4択クイズ（全20問）。単一HTMLファイルのみで動作します。

**▶ プレイする: https://youzoom64.github.io/economics-quiz/**

## 特徴

- 全20問・4択（GDP、インフレ、需要と供給、金融政策、財政、経済学者 など）
- 1問ずつ回答 → 即座に ○× と解説を表示
- 最後に「◯ / 20問正解」と評価、間違えた問題は自分の解答と正解を一覧表示
- 選択肢の並びは毎回シャッフル
- 依存ライブラリなし・ダークモード対応・スマホ対応

## 使い方

`index.html` をブラウザで開くだけです。
