# 経済 4択問題集

経済の4択クイズ。初級・中級・上級の3レベル、各20問。依存ライブラリなしで動きます。

**▶ プレイする: https://youzoom64.github.io/economics-quiz/**

| レベル | 内容 | 出題例 |
| --- | --- | --- |
| [初級](beginner.html) | 基本用語としくみ（高校の政治・経済レベル） | GDP、インフレ、需要と供給、円高円安、金融・財政政策 |
| [中級](intermediate.html) | 制度と統計指標＋簡単な計算 | 三面等価、GNI、乗数、プライマリーバランス、コアCPI、経常収支、関税 |
| [上級](advanced.html) | ミクロ・マクロ理論と計算（公務員試験・経済学部レベル） | IS-LM、流動性の罠、マンデル＝フレミング、独占価格、コースの定理、信用創造、消費者余剰 |

## 仕様

- 1問ずつ回答。**回答直後に正誤は表示せず**、20問終わってからまとめて発表
- 結果画面に「◯ / 20問正解」＋全問の ○× 一覧・正解・解説
- 選択肢の並びは毎回シャッフル
- ダークモード対応、スマホ対応

## 構成

```
index.html          レベル選択
beginner.html       初級20問
intermediate.html   中級20問
advanced.html       上級20問
assets/quiz.js      共通エンジン（各ページの QUESTIONS 配列を読んで動く）
assets/quiz.css     共通スタイル
```

問題を足すときは、各HTML内の `QUESTIONS` 配列に
`{q:"問題文", c:["選択肢4つ"], a:正解のindex, e:"解説"}` を追加するだけです。
